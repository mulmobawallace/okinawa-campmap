# 沖縄キャンプまとめ

沖縄で行われるプロ野球（NPB・KBO・CPBL）・Jリーグのキャンプ情報を、地図とカード一覧で見られる静的サイトです。プロ野球は2月の春季キャンプと10〜11月の秋季キャンプ、Jリーグは秋春制移行後の夏キャンプ（7月ごろ）も掲載しています。各レコードの `year`（年度）で、地図・グリッド画面の表示年度を切り替えられます（初期表示は今年（日本時間）の年度。今年のデータがなければ、今年以前で最新の年度）。

- `index.html` — グリッド表示にリダイレクト
- `grid.html` — カード一覧（ジャンル別／月別で切り替え）
- `map.html` — 地図（ピン表示）
- `data.json` — キャンプデータ（読み取り専用）

このサイトは静的HTMLのみで動作し、サーバーは不要です（GitHub Pagesで公開できます）。データの更新は `data.json` を編集して再度公開してください。
